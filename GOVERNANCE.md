# Governance

## Maintainers

Pagehall currently has a single maintainer, who founded the project. The maintainer reviews and merges pull requests, decides on the roadmap and releases, and handles security reports and code of conduct reports.

Further maintainers may be added from regular contributors who have shown sustained, high-quality work and good judgment in reviews. New maintainers are proposed by an existing maintainer and announced in GitHub Discussions.

## Decisions

- Day-to-day decisions are made in issues and pull requests.
- Significant technical decisions are proposed and discussed publicly in GitHub Discussions before they are made.
- The maintainer makes the final decision when there is no agreement.
- Pagehall is free software without paid tiers or an enterprise edition. Decisions do not create features that are reserved for some installations.

## Contact

Security vulnerabilities are reported as described in [SECURITY.md](SECURITY.md). Code of conduct reports and other private matters are sent to the maintainer through GitHub private vulnerability reporting as well, marked as a conduct report, until a dedicated contact address exists.

## Changes to this document

Changes to this document are made through pull requests and are announced in GitHub Discussions.
