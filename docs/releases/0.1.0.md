# Lunedo 0.1.0

Lunedo is a free, self-hosted wiki, knowledge base and planning tool for teams and companies, licensed under the AGPL-3.0. 0.1.0 is its first release. Every feature is available to every installation: no paid tiers, no license keys, no seat counting.

## What Lunedo 0.1.0 can do

**Write and organize**

- Spaces with a tree of pages, folders, links and whiteboards. Every item has a number, and its address stays valid when it is renamed or moved.
- A block editor with headings, lists, tables, tabs, embeds, file previews, reports and diagrams, inserted with `/`.
- Editing together in real time on pages, blog posts and whiteboards, with the cursors of everyone who edits.
- Publish mode with drafts and published versions, or live mode; a page status such as "In progress" or "Verified"; owners, trash and archive; copying pages, folders and whiteboards.
- A blog in every space, meeting series with meeting notes, topics and a decision log, and tasks with assignees and due dates.
- draw.io, Mermaid and PlantUML diagrams and Excalidraw whiteboards, served by the instance so they work without internet access.
- Page properties, reports and reusable content that only ever show what the viewer may read.
- Built-in templates in English and German, own templates for the instance, an organization or a space, and template files to share them.

**Share knowledge**

- Knowledge bases with areas, topics and articles, read in a portal of their own, with audiences, translations, regular reviews and a download as a static website.
- Search over everything a person may read, with filters.
- Sharing with people and groups outside a space, share links, view and edit restrictions, and confidential spaces that administrators cannot open.
- Notifications in the app, by e-mail and as browser push messages, and chat channels to Microsoft Teams, Slack, Discord, Matrix or any webhook.
- Export as PDF, Word, HTML or Markdown.
- Imports from Confluence (export file or API), Markdown folders and Word documents, reviewed in a quarantine space first and repeatable for newer content.

**Run it with confidence**

- Sign-in with password and second factor or passkey, and through Microsoft Entra ID, Google Workspace, OpenID Connect, SAML 2.0 and LDAP or Active Directory, with provider groups and SCIM.
- Organizations, groups, roles, guests, invitations, service accounts and API tokens, and an HTTP API described on every instance at `/api/docs`.
- Encryption of stored secrets, files and backups; encrypted backups on a schedule to a directory or S3-compatible storage, with test restores and a backup before every update.
- A setup assistant with a system check, a system status page, maintenance mode, an update check, Prometheus metrics and an audit log.

The full list is in the [changelog](https://github.com/lunedo/lunedo/blob/v0.1.0/CHANGELOG.md).

## Install

Lunedo runs with Docker Compose next to PostgreSQL 16, 17 or 18. On a Linux host with Docker Engine 24 or newer:

```sh
curl -fsSLO https://github.com/lunedo/lunedo/releases/latest/download/install.sh && bash install.sh
```

The script asks for the installation directory and the address people open, starts Lunedo and prints a setup link. Open it to create the owner account and the first organization, then put a reverse proxy with TLS in front of Lunedo and keep `.env` in a safe place: it holds the keys without which a backup cannot be restored.

- [Installation](https://lunedo.org/docs/admin/installation/), also with your own Compose file
- [Requirements](https://lunedo.org/docs/admin/requirements/)
- [Reverse proxy](https://lunedo.org/docs/admin/reverse-proxy/)
- [Setup assistant](https://lunedo.org/docs/admin/setup-assistant/)

## Known limitations

- A search with more than 1,000 matches counts and ranks only the 1,000 most recently changed of them, so broad searches on large instances prefer recently changed pages. More words narrow the search. See [Searches at once](https://lunedo.org/docs/admin/requirements/#searches-at-once).
- The hardware requirements and response times were measured on one reference machine with 4 vCPU and synthetic content, described in [Measured requirements](https://lunedo.org/docs/admin/requirements/#measured-requirements). Other hardware, storage and content behave differently; check the numbers against your own instance.
